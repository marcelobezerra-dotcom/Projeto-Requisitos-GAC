- **Tipo:** blog (fabricante)
- **Resumo (máx. 200 palavras):** O texto compara os dois tipos de sensor de impressão digital mais usados comercialmente. O sensor óptico captura uma imagem da digital usando luz e um sensor de imagem, comparando padrões de claro/escuro entre cristas e vales; é mais barato e adequado a aplicações de baixo custo (escolas, ponto eletrônico, controle de acesso simples), mas é mais volumoso e mais fácil de enganar com uma imagem de boa qualidade. O sensor capacitivo mede diferenças de carga elétrica entre cristas e vales, produzindo um mapa mais detalhado; é mais compacto (por isso domina em smartphones e laptops), mais preciso e mais resistente a spoofing, porém custa mais para fabricar. O artigo recomenda óptico para implantações sensíveis a custo e capacitivo para aplicações de alta segurança (bancos, identificação governamental, controle de acesso corporativo).
- **Principais ideias / insights:** custo e segurança são inversamente relacionados entre os dois tipos de sensor; a escolha do sensor deve ser guiada pelo caso de uso, não só pela tecnologia mais "moderna".
- **Métodos / tecnologias usados:** comparação técnica descritiva, sem experimento próprio.
- **Pontos relevantes para o projeto GAC:** ajuda a justificar, no PoC, a escolha de um sensor óptico USB de baixo custo como opção mais viável para um protótipo acadêmico, deixando o capacitivo como opção para uma eventual versão "produto".
- **Questões geradas / hipóteses:** um sensor óptico barato seria suficiente para o nível de precisão exigido pelo PoC, ou o índice de falsa aceitação/rejeição inviabilizaria o uso em um cenário real?
