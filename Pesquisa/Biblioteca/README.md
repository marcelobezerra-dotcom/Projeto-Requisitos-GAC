# Biblioteca de Pesquisa

Esta pasta centraliza textos, artigos, papers, links e fichas de leitura usadas nas pesquisas do projeto.

Estrutura sugerida:
- `Pesquisa/Biblioteca/Fichas/` — fichas de leitura por referência (MD)
- `Pesquisa/Biblioteca/Papers/` — PDFs ou links salvos
- `Pesquisa/Biblioteca/links.md` — lista de links úteis e referências rápidas

Como usar:
- Crie uma ficha de leitura em `Fichas/` usando o template `ficha-de-leitura-template.md`.
- Ao usar um paper externo, adicione o PDF em `Papers/` ou um link em `links.md`.
