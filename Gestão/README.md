# Gestão

Pasta para arquivos de governança, atas de reunião, pautas e registros administrativos do grupo de estudo GET.

Estrutura:
- `Atas/` - atas e pautas de reunião
- `scripts/` - scripts de automação (criar milestones, labels, issues) e `config.json`

Use esta pasta para armazenar decisões, cronogramas e registros formais do projeto.

Automação:
- Veja [Gestão/scripts/README.md](Gestão/scripts/README.md) para instruções sobre como gerar milestones, labels e issues a partir de `config.json`.
