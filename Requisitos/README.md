# Requisitos — organização do repositório

Esta pasta (`Requisitos/`) agora contém apenas documentos relacionados aos requisitos do sistema, como casos de uso, diagramas, entrevistas e artefatos formais de requisitos.

Arquivos e templates relacionados a pesquisas, PoCs e experimentos foram movidos para `Pesquisa/Work/` para centralizar tudo o que é investigação e prototipagem.

Principais itens movidos:
- `Pesquisa/Work/Documento-Visao.md` — template de documento de visão
- `Pesquisa/Work/SDD-Resumo.md` — resumo do SDD
- `Pesquisa/Work/POC-README-template.md` — template para PoC
- `Pesquisa/Work/Roteiro-Pesquisa.md` — roteiro e checklist para alunos

O que fazer se você depender dos arquivos antigos:
- Atualize links e referências que apontavam para `Requisitos/Work/` para usar `Pesquisa/Work/`.
- Se preferir, posso criar redirecionamentos (README com links) ou PRs para atualizar referências em todo o repositório.

Objetivo desta reorganização: separar claramente os artefatos de pesquisa/protótipo da especificação formal de requisitos, facilitando revisão, entrega e avaliação.
