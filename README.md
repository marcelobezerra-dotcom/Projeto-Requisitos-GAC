# Projeto Requisitos - Visão Geral

Este repositório contém os requisitos, protótipos e materiais do projeto de empréstimo de projetores.

Estrutura principal:
- `Pitch/` - materiais de apresentação
- `Prototipos/` - protótipos e telas
- `Requisitos/` - casos de uso, entrevistas e visão do produto

Veja os READMEs nas subpastas para detalhes específicos.
